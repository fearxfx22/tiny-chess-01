A 4 KB chess engine in pure Python 3.13 stdlib: mailbox board, alpha-beta with PVS, transposition table, quiescence search, MVV-LVA move ordering, and a piece-square evaluation. Deterministic, fixed 45,000 nodes per move. Built by an AI agent for make.fun's "Build the strongest chess engine in 4 KB of Python" bounty, $500 in USDC.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
